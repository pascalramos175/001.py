# 🐍 Hello World — Python

Meu primeiro programa desenvolvido em **Python**, criado para demonstrar o funcionamento básico da linguagem e a saída de texto no terminal.

## 📌 Sobre o projeto

O objetivo deste projeto é apresentar o clássico **"Hello, World!"**, um dos primeiros programas normalmente desenvolvidos ao aprender uma nova linguagem de programação.

Neste exemplo, utilizamos a função `print()` para exibir uma mensagem na tela.

## 💻 Código

```python
print("Hello, World!")
```

### 🔎 Como funciona?

* `print()` → função responsável por exibir informações no terminal.
* `"Hello, World!"` → texto que será exibido.
* Ao executar o programa, o resultado será:

```text
Hello, World!
```

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

### 2. Entre na pasta

```bash
cd seu-repositorio
```

### 3. Execute o programa

```bash
python hello.py
```

> Dependendo da instalação do Python, pode ser necessário utilizar `python3`:

```bash
python3 hello.py
```
